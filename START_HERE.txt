AEROL — ASTRONAUT WATCH + EARTH RESEARCH DASHBOARD

1. Install Python 3.9 or newer (no extra packages needed).
2. In this folder run:   python3 -m aerol
3. Open http://127.0.0.1:8000/        (astronaut watch)
        http://127.0.0.1:8000/dashboard/  (Earth research dashboard)
        http://127.0.0.1:8000/mobile/ (watch only, phone)

Read README.md, then docs/DEMO.md for the 7-step demo.
All devices are simulated. Not a medical device. No real messages are sent.
Tests: python3 -m unittest discover -s tests    and    node --test tests/js/*.test.mjs
