AEROL — EDITABLE TEAM SOURCE

1. Unzip this entire folder.
2. Install Python 3.10 or newer if needed.
3. Open a terminal in aerol-team-kit and run:
   python3 -m aerol
4. Open http://127.0.0.1:8000/
   Phone layout: http://127.0.0.1:8000/mobile/

EDIT THESE FILES
- Dashboard behavior: aerol/static/app.js
- Dashboard appearance: aerol/static/styles.css
- Desktop / phone entry points: aerol/static/index.html and mobile.html
- Python API and storage: aerol/server.py
- Connect the prediction model: aerol/model_adapter.py

Read README.md and docs/MODEL_HANDOFF.md before connecting a model.
No third-party dependencies are needed to run this starter.
The prediction model is an integration stub; no trained model is supplied.
NASA source data and provenance are included.
